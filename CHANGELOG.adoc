= Changelog

== [0.1.2] - 2026-10-20

=== Changed

* Marker discovery uses fixed `.antora-source-id` only; match after reading `id:` / `url:` in file body (same as Node v0.2.2).

== [0.1.1] - 2026-10-20

=== Added

* Windows NTFS MFT filename scan (`source/mft_search.d`) with per-drive index cache for one `resolve` run.
* Request field `searchMethod` (`auto` | `mft` | `walk`); report methods `mft-search` / `mft-first-match`.

== [0.1.0] - 2026-10-20

=== Added

* `resolve` subcommand: JSON request/response matching `@antora-supplemental/antora-local-content-sources`.
* Upward-then-drive marker search with parallel drive scans (`std.parallelism`).
* Duplicate-clone warnings on stderr; `matches`, `conflict`, and `overrideUsed` in report JSON.
* GitHub Actions CI and release matrix (windows-x64, linux-x64, macos-arm64).
